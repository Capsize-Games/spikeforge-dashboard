Download and installation

SpikeForge Desktop includes a local, CPU-only engine. Python and Docker are not required.

Windows x64

  1. Download the Windows x64 ZIP from itch.io.
  2. Extract the archive.
  3. Open the extracted folder and run SpikeForge Desktop.exe.

Linux x64

  1. Download the Linux x64 .tar.gz archive from itch.io.
  2. Extract the archive.
  3. Run the included AppImage.

If your distribution reports a FUSE error, install its FUSE 2 compatibility package and try again.

Your data

Datasets, model downloads, checkpoints, and logs are stored in your operating system's per-user application-data directory. Removing the downloaded application does not automatically remove that data.

Troubleshooting

If the bundled engine cannot start, use the application's Open log option when it appears. GPU acceleration, CUDA, and optional hardware-vendor SDKs are not included in this desktop build. The open-source Python and Docker installations support those configurations.
